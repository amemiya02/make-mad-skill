# 17 顶级 MAD 的剪辑思路与特效使用规则（证据版）

> 诚实声明：下列"实例观察"全部来自 ffmpeg 抽帧（1fps 总览 + 6fps 细看 + 场景检测/亮度统计），**没有真正观看或收听**。
> 标 [推断] 的是由帧序列推出的结论，不是直接证据。cut 数为 `scene>0.3` 且去重(0.25s) 的结果，会把原作内部的快速作画切换也算进去，
> 所以绝对值偏高，只用于比较"曲段之间的密度变化"。原始文件/抽帧放在项目的 `analysis/refs-top/`（不随 skill 分发）。

## 1. 顶级 MAD 的核心思路

1. **特效是"原素材的延伸"，不是"贴上去的装饰"。** AnimeMusicVideos.org 社区共识（搜索摘要，页面 403 未能全文读取）：
   "你的特效不应驱动视频，是视频驱动你的特效使用"；"观众若想到'这特效真酷'，说明你用得太显眼"；
   观众被特效打动 = 观众没在关注情感/故事。
   https://www.animemusicvideos.org/forum/viewtopic.php?t=92942 （So You Want To Be A GOOD AMV Editor）
2. **闪白/节拍特效是最容易滥用的东西。** 同站"最烦人/最滥用特效"讨论（搜索摘要）：高潮点一次闪白可以加料，**每拍都闪是骚扰**；
   flips/spins/zooms/zips 等 Premiere 预设类转场是典型业余标志。
   https://www.animemusicvideos.org/forum/viewtopic.php?t=129889
3. **硬切是默认；溶解/淡出留给抒情、回忆、收束。** 通用剪辑理论：hard cut 直接、保能量、不抢戏；cross dissolve / fade 适合情绪、回忆、收尾。
   https://uppbeat.io/blog/motion-graphics/video-transitions ；https://www.capcut.com/create/video-transitions-crossfade-hard-cut-jump-cut
4. **"高手靠审美，不靠技术"。** 日在风蓝技术组 MAD 入门：PR 内置转场"很 low"；结论"MAD 对艺术审美的要求高于技术"；选镜体现审美；
   学习路径是大量看、模仿成品。https://static.aoikaze.moe/second-wordpress-site/2159/
5. **剧情向 MAD 的第一要务是叙事连贯**，不能因为"好看"就塞镜头；所有特效必须服务内容表达，否则只是炫技
   （知乎相关讨论摘要：zhihu.com/question/394744283，403，仅摘要；"MAD 是什么"：https://www.gcores.com/articles/16897 ——
   MAD 分静止系/动画系，创作者视作品为"自己的孩子"，强调个人表达）。B 站"MAD/二创理论课#1 剪辑思维"
   （バカ犬，9.3 万播放）主旨同样是"思维先于插件特效"：https://www.bilibili.com/video/BV1kT4y157H4/ （仅读到简介）。
6. **节奏要有对比。** 全程同一速度（无论快慢）会杀死情感质感；快慢对比才让两者都有力。快切=紧张，长镜=亲密/回味。（通用剪辑文章摘要）
7. **卡点特效预设是"反面教材"的来源。** 市面 CapCut/AMV 预设（shake intensity 30-45、0.2-0.4s；zoom blur 0.2s；glow+flash 贴每个 beat drop）
   正是用户拒绝的那一类；这类内容面向 TikTok/Reels 短平快（sabukaru 文章：Instagram AMV 快切多特效，YouTube AMV 更长更慢、多整段原场景）。
   https://www.scribd.com/document/996960216/Ultimate-AMV-CapCut-Preset-Guide-2026 ；https://sabukaru.online/articles/visual-remix-culture-the-legacy-of-amv
   通用提醒：glitch/strobe 容易过时，只能短促用，不能当整段转场（miracamp / insideeditors 摘要）。
8. **cut on action、保持视觉焦点一致。** 切点放在动作中途、相邻镜头主体位置相近（AMV.org "Editing action amvs"，摘要）；
   淡黑不要降到 0%，别低于约 20% 不透明度，否则刺眼（AMV.org，摘要）。

## 2. 实例拆解（4 条，全部 ≤720p，抽帧分析）

分析口径：`cpm` = 去重后 cuts/min；每 30s 窗口 cpm 用于看曲段起伏。

### 2.1 Frieren「Haru / Sunny」Yorushika（【MAD】，YT 1559 万播放，抒情中速，271s）
URL：https://www.youtube.com/watch?v=LTGkt3GrGNY　文件 LTGkt3GrGNY.mp4
- 整体 cpm 50，中位镜头 0.96s，p90 2.0s；窗口 cpm：34, 48, 54, 38, 72, 58, 46, 66, 36（开头/结尾低，副歌段高）。
- **转场**：绝大多数硬切。唯一的"软"处理：**32–35s 约 3s 的多层叠化**（手/队伍/眼睛多重曝光，色调统一成青粉）——放在安静的回忆段；248–249s、268s 淡出到黑收尾。
- **白帧**：77.3s、146.6s、166.5/168.5s、169.6s 的亮帧**在 6fps 细看下都是原作的魔法爆发/光效镜头**（73.5s 黑白漫画框特效、74.8s 十字光爆也是原作）；
  剪辑只是把切点卡在这些原作光效上，**没有额外加闪白**。[推断：根据 6fps 帧序，未对比原片]
- **抖动/缩放**：6fps 下各镜头保持构图稳定（如 36.0–37.3s 静止立绘、192.0–193.0s 山景、43–45s 角色背影）；**未见叠加数码抖动或推拉**。
- **能量来源**：①选镜（光、花、风、手的特写交替）②切点对齐原作动作/光效③副歌窗口镜头变短（72/66cpm）④色彩主题（蓝-绿/暖金大块色相轮流）。
- **文字**：全片 0 个标题/歌词/署名（抽帧可见范围内）。**调色**：不统一调色，保留原作色彩，靠"按色相排序/邻接"来连贯。
- **没做**：没有 roto/抠像、辉光描边、径向爆发、数码震动、标题卡、闪白预设。

### 2.2 Mushoku Tensei「Before You Go」（Captain Highwind，YT 29.8 万，抒情，258s）——**同源作品，最贴近我们**
URL：https://www.youtube.com/watch?v=ory-5LYsecE　文件 ory-5LYsecE.mp4
- cpm 30.7，中位 1.13s，p90 3.0s；窗口 cpm：36, 16, 10, 28, 52, 48, 34, 30, 10。**开头 0–1s 黑场淡入，结尾 ~255s 起淡出黑，约 2s。**
- 叙事：按原作时间线讲 Eris–Rudeus 的关系（0–70s 童年相遇/被囚夜路 → 100–150s 舞会/牵手 → 150–200s 战斗与重逢 → 210–255s 分别/信/烛光）。
  **前 60s 低密度（cpm 10–16）铺情境，120s 后升到 52/48，最后 30s 回落到 10。**
- **转场**：全片硬切。唯一的"亮"处：155–159.5s 一段**原作的青色光柱爆发**（153–157s 逐步变亮，158.8–159.4s 近白 0.44s），之后硬切到火光镜头——光是原作的，剪辑只是顺着它切。
- **抖动/缩放/闪白/特效**：6fps 下同一镜头内人物构图稳定（如 64–67s 表情特写、100–102s 托腮特写 3s 不动、152–153s 舞蹈远景）；无叠加数码特效。
- **长镜头用法**：表情特写 2–3s 静置让情绪沉淀（如 99–102s、109–112s 的 Rudeus 脸），**不靠推镜"制造情绪"**。
- **文字**：无。**调色**：无统一调色，原作冷蓝夜戏与暖光戏直接相接，靠"从暗到亮"的叙事自然过渡。
- **没做**：标题卡、歌词字幕、闪白、抖动、缩放脉冲、roto、辉光。

### 2.3 "A Drop Of Hope"（Baka Oppai，Animefest 2013 Drama 获奖，YT 218 万，多作品混合，259s）
URL：https://www.youtube.com/watch?v=_GqyVfe_hKg　文件 _GqyVfe_hKg.mp4
- cpm 18.8（四条里最低），中位 1.62s，**p90 10.9s**（有 5s 以上的长镜头，如 131–135s 同一侧脸）；窗口 cpm：16, 14, 8, 16, 14, 34, 38, 16, 6。
- **转场**：这条最爱用软转场，但**全是"光/色/形状匹配后叠化"**：
  - 96–98s 金色夕阳逆光 → 白色羽翼（亮度/色温匹配）；99.8–103s 白色嘴部特写 → 叠化到青色发光的小孩 → 光晕蔓延到白色街道（≈1s 叠化，全程匹配亮度）。
  - **唯一一次"闪白"**：181.7→183.2s，青色水中光爆（原作的光晕）逐渐变亮 → 近白 0.5s（182.8–183.2s）→ 叠化接到一只摊开的手（183.3s 起）。
    它出现在**全片情绪最高点前后（≈70% 位置）、只此一次、由原作光效过渡而来、下一镜语义相接（"光→伸手"）**。
  - 开头 0–50s 低 cpm（16/14），一把吉他/歌唱女孩的镜头 2–3s 一个；**50–53s 全黑 3s 作为段落分隔**；235–237s 黑场 + 结尾制作组标识（"BAKAOPPAI" 字样，仅出现在结尾，238s 起）。
- **抖动/缩放**：无可见；镜头保持原作构图。**镜头之间用色彩（金/青/雪白）的块状相邻做"调色统一"**——靠选镜+排序，不靠滤镜。
- **没做**：roto/抠像、闪白连打、径向爆发、数码抖动。

### 2.4 Magnetic Rose「You Will Never Leave Me…」（maboroshistudio，Anime Expo 2018 Best Drama，YT 1.5 万，232s）
URL：https://www.youtube.com/watch?v=ML5oKWDdHnY　文件 ML5oKWDdHnY.mp4
- cpm 33.6，窗口 cpm：6, 36, 10, 26, 60, 54, 46, 22。**开头 ~5s 全黑**（0–4s）后 5s 才出画面；多处 **全黑隔断**：24s、42–43s、54–55s、58–59s、131–132s、156–158s、173–175s。
- 这条**确实用了数码特效，但全部由题材支撑**：原作是"鬼屋/记忆幻觉"科幻恐怖，故事内含全息投影与干扰——

## 3. 特效使用规则（do / don't）

| 手法 | 顶级剪辑师何时用 | 何时显业余 | 可测量上限 |
|---|---|---|---|
| 数码抖动 shake | 只在**原作自带冲击**（爆炸/重击）且主旨是动作的段落；实例 4 条中 0 条叠加 | 叠在平静镜头、每拍都抖、预设 intensity 30–45 | 抒情 MAD：**0 次**；动作段若用，≤0.25s、≤3px、整片 ≤3 次 |
| 缩放脉冲 punch-in | 几乎只出现在快节奏/音 MAD；抒情实例 0 次 | 每个 beat 一次脉冲；对静帧推 | 抒情：**0 次** |
| 慢推 push-in（由远及近）| 原作自己有镜头运动时直接用；用于单个"情绪点"的静帧偶尔一次 | **每个镜头都推** = 机械、让所有镜头同一种"呼吸" | 整片 ≤ 3–5 个镜头，且 ≥3s、总缩放 ≤4%、不得连续两镜头 |
| 闪白/白帧 | 整片 1 次大闪白，放最高点；或顺着原作自带光效切 | 镜头之间用白闪连接；每拍闪 | 主动加的闪白：**整片 ≤1 次**，时长 ≤0.5s（前带 0.5–1s 渐亮 + 之后叠化）；绝不在连续镜头之间重复 |
| roto/抠像 | 极少；要么原作本来就有（剪影/逆光）要么做"蒙版揭示"并且无描边 | 抠像定格 + 外发光描边 + 径向爆发背景（AI 贴纸感）| 抒情 MAD：**0 次**；若用，无外发光、无 radial burst |
| 辉光 glow/bloom | 柔光整体提升高光（调色级别），人眼看不出"特效" | 沿人物轮廓描光边 | 整幅 bloom 强度 ≤ 原画高光的 15%（[推断]）|
| 变速 speed ramp | 动作冲击点前后（原作本来就快），或 0.5× 的慢放强调一个动作 | 对情绪镜头打"节拍变速" | 抒情 MAD ≤ 2–3 个，仅动作镜头 |
| 溶解 dissolve | 回忆/时间流逝/光→光匹配、段落收束；时长 0.5–1.5s | 随机每镜头叠化；用叠化代替硬切 | 抒情 MAD ≤ 10–15% 的转场；每处必须有色/光/形匹配 |
| 淡黑 fade | 开场、段落分隔、结尾（2–3s）| 降到 0% 又立刻硬起；每段都淡 | 整片 3–7 次；开 0.5–3s、收 2s |
| 匹配切 match cut | 色相/亮度/构图/动作方向一致（金→白、手→手、眼→眼）| 为了切而切、焦点跳到另一侧 | 是"软转场"的首选替代；尽量让 30–50% 的切点有一种匹配 |
| 文字/歌词 | 全程无字，或只在结尾放一行制作署名；歌词字幕仅在用户明确要求时，且排版克制 | 标题卡写歌名（"we're making a MAD, not an MV"）；每句歌词弹跳入场 | 抒情实例：文字 0–1 处；片头标题卡 **0**|
| 标题卡 | 无（片头直接从黑场/第一个画面起）| 歌名/作品名 logo | **0** |
| 原作对白 | 作为叙事锚点，段落间极少（需无 BGM 干净对白）；通常音乐不停 | 冷开场一大段无音乐对白；对白与歌声重叠 | 若用：≤ 2 句、≤ 6s、不得在开头 |
| 调色 | 不改色，靠排序/邻接做统一；或整片统一轻微 LUT | 每镜头不同滤镜；极端色偏 | 实例：无统一滤镜；若加 LUT，镜头间平均色温差 ≤ 300K（[推断]）|
| 黑场/静默 | 开头 0.5–5s 黑场（Magnetic Rose 5s）；段落间 1–3s | 超过 3s 无画面且无理由 | 开场 ≤ 3s 黑 |

## 4. 对「光の唄」类抒情慢歌 MAD 的具体建议（4.5 min，渐强）

结构取自 4 条实例的 cpm 曲线 [推断为映射到歌曲段落]：

| 曲段 | cpm | 平均镜头 | 手法 |
|---|---|---|---|
| 0–0.5s | — | 黑场淡入（0.5–2s）| 无标题、无对白冷开 |
| 前奏/主歌1 | 10–24 | 2.5–6s | 长镜头、表情特写、风景；偶尔 1 个叠化（回忆）|
| 前副歌 | 24–36 | 1.5–2.5s | 随旋律推进逐渐缩短；对切点：在乐句/呼吸后落点 |
| 主歌2 | 16–30 | 2–3s | 稍回落，叙事推进，保持原作镜头运动 |
| 副歌1 | 40–55 | 1–1.5s | 选"动作/光"镜头，切点对齐鼓点/和弦换位 |
| 桥段/间奏 | 8–20 | 3–10s | 最长镜头，静默的情感点（实例中 p90 最长 10s+）|
| 终段大副歌 | 50–72（全片峰值）| 0.8–1.2s | 靠**镜头变短 + 原作中最有冲击的镜头 + 原作光爆**制造高潮；可有 **1 次** 主动闪白/光爆叠化 |
| 尾声 | 6–10 | 4–8s | 回落，长镜头 + 2s 淡黑 |

**没有假抖动怎么造能量：**
1. 镜头变短（中位 1.5s → 0.8s）；峰值 cpm / 低谷 cpm ≥ 3×。
2. **选镜"能量排序"**：低→中→高（静态特写 → 行走/奔跑 → 战斗/魔法光效）。能量由原作画面提供。
3. **切点放在原作动作/光效上**（如实例 1 对原作魔法爆发、实例 2 对光柱的切法）；用 cut on action 保持焦点一致。
4. 色彩/亮度递进：暗冷 → 暖亮（实例 2、3 都是从暗到亮），高潮时亮度最高。
5. 利用原作自带的镜头运动（pan/tilt/追拍）；**不要在静止立绘上叠加数码运动**。
6. 对比：副歌前先有 1–2 个"静"的长镜头，再进入高密度（先静后爆）。

**副歌高潮如何做（有证据的做法）：**
- 实例 3：高潮前 20s 渐亮（光/水/金色）→ 原作光爆吃满画面 → 0.5s 近白 → 叠化到摊开的手（语义相接）。
- 实例 1：副歌窗口 cpm 66–72，镜头多为光/花/魔法大场面，切点对原作爆点。
- 实例 2：120–150s cpm 48–52，内容是舞会/牵手的高情感镜头，高潮的"能量"来自**情感事件**而不是特效。
- 实例 4：RGB 色散只在 4 个点、每次 <0.5s，且题材合理；**不要把它当通用特效**。

**对话**：我们的素材如果要用对白，只在 **音乐已进入且旋律留白**处出现，≤2 句，必须是干净对白；不要作为开场。

## 5. 自检清单（渲染前逐条打勾）

- [ ] 整片**没有**数码抖动叠加（动作段例外 ≤3 次，每次 ≤0.25s）。
- [ ] 整片**没有**对每个镜头的统一慢推；推镜头 ≤5 个、每个 ≥3s、≤4%。
- [ ] 主动闪白 ≤1 次，位置在全片最高潮，有渐亮和叠化，且上下镜头语义相接；原作自带光效不叠加额外闪白。
- [ ] 无 roto 辉光描边 / radial burst / 闪电 glitch 叠层转场。
- [ ] 无标题卡、无歌名字幕；片头从黑场/第一帧画面直接开始；结尾 2s 淡黑。
- [ ] 无"冷开场对白"（无音乐的原声）。
- [ ] 硬切 ≥85–90% 的转场；软转场（叠化/淡黑）每处都有色/光/形/动作匹配。
- [ ] cpm 曲线：峰值/谷值 ≥3×，前奏低、终副歌最高、尾声回落；每 30s 窗口有可解释的变化。
- [ ] 至少 3–5 个 ≥3s 的长镜头（情感停留），最长 ≥8s。
- [ ] 没有 <0.25s 的闪镜头（除原作自带），没有每拍 1 次的规律性特效。
- [ ] 色彩连续性：相邻镜头色温/亮度突变处有匹配或叠化；若加整片 LUT，只做轻微统一。
- [ ] 用 `ffmpeg scene` 重测成片：cpm 曲线、亮度>225 的帧（必须是原作光效或唯一的那次闪白）、黑场时长，再逐 30s 抽 6fps 联系表人工看。
- [ ] 用户红线复核（见 memory：完整歌词、干净对白无 BGM、无填充/缩放/闪帧、无信箱切换、AE 级特效）：此文档与红线冲突时以红线为准。
