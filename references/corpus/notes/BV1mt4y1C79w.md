## 8. 可迁移到「光の唄」无职MAD的经验
1. 艾莉丝修行段：用 #57–#74 的做法，选一个「连续的形状/运动」母题（比如艾莉丝的剑尖/红发/衣摆/落叶）做 10–18 个 0.1–0.5 s 的镜头串，让每次切换后主体仍在同一位置、运动方向与上一镜相同，其余用 2–3 s 的呼吸长镜头两头夹住（#46、#75）。
2. 叙事：学习「主线 + 别人的故事（Ann）+ 终段回扣」。无职可以用「鲁迪乌斯 → 旧鲁迪乌斯警告 → 艾莉丝修行/死亡 → 家人」，终段把所有人物以叠印+回忆滤镜串一次。
3. 结尾：最后用「长近景（#136 6.9 s）→ 物件特写（#139 胸针 3.1 s）→ 一朵象征花（#140 6.5 s）→ 溶解 → 黑」。对应无职可以是：鲁迪乌斯流泪近景 → 艾莉丝的剑/发饰 → 一朵花或一片树叶 → 黑。
4. 回忆语言：只用一种（米白过曝溶解 + 奶油滤镜 + 淡叠印字），其他地方不要乱加溶解。
5. 遮幅：全程固定，不切换；字幕放在黑边里，不压画面。
