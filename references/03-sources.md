# 素材获取与洁净源协议

具体搜索入口、下载命令与逐项取得证据见 [获取指南](13-anime-acquisition.md)；本页负责设计与验收规则。

## 三个不同的集合

研究参考：别人完成的MAD，用来学习表达，不默认有权作为自己的素材剪入。
原始画面源：动画正片、无字OP/ED、官方提供的洁净片段、授权片源、用户可合法使用的本地母版。
辅助资产：漫画/插画、字体、音效、纹理、3D模型等，分别记录来源和使用范围。

官方预告也可能烧录标题/Logo；无字OP也未必覆盖正片需求；正规获得的文件也不自动解决剪辑发布范围。按实际证据记录，不用“网上能看”“非商业”“署名了”替代核对。这里是制作溯源协议，不提供特定地区的法律结论。

## 获取流程

先根据分镜列素材需求，再按作品/集数/发行版本寻找。优先官方可下载资源、明确允许相关用途的资源或用户已经合法持有的高质量文件。不能为了凑文件数量下载不匹配版本。

下载之前核对来源、是否允许下载、可用分辨率与轨道、预期大小、版本与是否涉及账号/费用。需要购买、登录、上传用户文件到外部平台等操作时取得相应授权。不得绕过DRM、认证或付费限制。

`mad.py fetch`是**确认后的直链获取器**，不是动画搜索引擎，也不是B站/流媒体破解器。它只接受HTTPS直接媒体URL，限制体积、检查媒体和1080p尺寸、生成来源侧车文件。有可信预期SHA256时验证，否则记录新文件指纹且标为未经独立校验。没有直链的站点使用它提供的正常下载入口；不可把网页HTML保存成`.mkv`交差。

```bash
python scripts/mad.py fetch /path/to/source-download.json --out /path/to/project/assets/video/source.mkv
```

来源侧车可能含私有下载URL，分享工程前去除签名参数和凭证。只下载不代表素材已通过艺术/清洁/使用范围审查。

## 1080p的两层核验

机器层：读取实际解码视频尺寸、帧率、扫描方式、时长、像素格式、色彩信息、轨道列表[T01]。基础交付门要求尺寸至少1920×1080；低于该尺寸不静默放大。宽银幕裁边版即使来源优良，也必须先明确改变需求，或取得完整1080p母版，不能让工具偷改用户要求。

内容层：查看100%原始画面，判断线条细节、压缩块、振铃、去噪涂抹、插帧扭曲、锐化边缘和已放大来源。写“native_quality=pass”意味着编辑者查验了版本与画质，不意味着ffprobe能证明原生分辨率。

不能用输出1920×1080证明源是1080p。使用代理时保留源ID、时间映射与帧率；合成/最终导出回套原始素材，重新看细节与重定时效果。

## 无字幕、无台标、无Logo

独立字幕轨可以不映射到导出；FFmpeg的`-sn`不会消除已经烧进像素的字幕。自动识别不是本包的洁净保证，OCR默认不运行。

先抽样建立索引；再**完整检查所有入选区间以及转场/变速余量**，尤其是OP/ED、片头/片尾、回顾、预告、电视台角标、短时提示、动态Logo。抽样中没看见不是不存在的证据。

工程里每个视频资产的`review.clean_ranges`登记实际查过的源秒区间；`evidence`指向审查记录。所有入选范围必须落入已查区间。图像素材逐张查，人物服装/场景固有文字与发行台标应区分记录。

不合格的首选处理是换源/换镜头。不得把自动裁剪、模糊、抹Logo、AI补洞当作本用户要求的无字幕生肉。作者主动加入的字幕另行设计，不能和原片残留字幕混为一谈。

## 镜头库与可追溯性

`probe`留元数据；`contact`生成带源秒数的缩略图；`scenes`输出镜头切分候选。镜头检测只缩小搜索范围，闪光、急摇、渐变、连续运动均可能误分[T02/T04]。

```bash
python scripts/mad.py probe source.mkv --out analysis/source-probe.json
python scripts/mad.py contact source.mkv --out analysis/source-contact --interval 30 --limit 60
python scripts/mad.py scenes source.mkv --out analysis/source-scenes.csv
```

从候选中回看真实片段，再填写`shot-log.csv`。不要声称已观看只抽了缩略图的全片。文件指纹、发行版和音画轨必须一致；同集不同版时间码不能直接混用。

预合成必须保留原始资产与使用区间的来源链。合成输出是1080p不能掩盖其上游使用了720p或带字幕原片。项目完成后仅在允许范围内分发媒体；来源账本与重建说明可与不可分发的原始文件分离。
