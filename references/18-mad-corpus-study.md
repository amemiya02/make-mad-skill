# 18 顶尖MAD语料研究：可测规律与可执行做法

**来源与边界**
- 2026-10 拆解了 B 站 42 部高播放/高收藏 MAD（另 2 部下载失败）：剧情向、燃向、群像，同系列《无职转生》4 部，以及用户参考 ZYL《FATE-EMIYA》。
- 工具是 `scripts/analyze_mad.py`，输出切点、转场类型、镜头长度、缩放/抖动、对拍率、密度-响度相关、shotboard 和转场条。
- 每部的逐镜笔记在 `mad-study/study/<BV>/notes.md`。
- 结论来自静帧与测量，不是观看/聆听体验。
- 检测器会把下列情况算成切点，所以 cpm 偏高：原作闪光、逐字文字、叠影串、同一原画的逐帧重复。
- 引用某部作品的“做法”时，以笔记里的 #idx 和时间为准。

## 1. 可测规律（拿来校准自己的剪辑）
| 指标 | 语料范围（典型） | 含义 |
|---|---|---|
| 硬切占比 | 83–98%，中位约 91% | 软转场是例外，每次都要有动机 |
| 溶解次数 | 0–30 次/4–5 分钟（个别叠化流 50–75） | 叠化多的片子靠全片统一暖色、亮度相近撑住 |
| cuts/min | 抒情/剧情 25–65；燃/群像 65–110 | 4.5 分钟单线叙事：全片 40–60，副歌峰值 ≤120 |
| 切在起音上（±1帧） | 多数≈随机（0.07–0.39 对随机 0.08–0.46），无一部系统性卡点 | 切点不追每个起音，要对齐的是乐句起点和镜头内动作顶点 |
| 密度-响度相关 r | 约一半 0.4–0.9；另一半≈0（由歌词/剧情决定） | 主歌疏、副歌密、桥段回落、结尾归零是最常见的曲线 |
| 长镜头 >3 s | 每部 10–35 个；5–12 s 的情绪节点 3–8 个 | 几乎都紧跟在快切串之后（快 → 停） |
| <0.5 s 镜头 | 好的抒情片 <35%；>50% 的片子笔记一致评价“碎、读不清” | 1080p 单作要让每个镜头读得清 |

## 2. 动作/修行段怎么接（解决“镜头衔接垃圾”）
顶尖作品很少靠“方向接力”或特效接动作段，靠的是下面几种。
1. **部位/阶段接力**
   - 握剑的手 → 挥剑的手；踏出的脚 → 落地的脚；甩动的红发 → 下一镜甩动的红发（利兹与青鸟 cut 50.80/117.67）。
   - 或者一个动作拆成阶段，每镜只负责一个阶段（苦夏 #44–#61：脚 → 腾空 → 投篮 → 篮筐）。
2. **同主体、同尺寸、同画位、换背景 = 时间流逝**（无职 onelastkiss #18–#27；数码宝贝坠落段）。
   - 不需要转场效果。
   - 原作里如果有发型、服装或季节的变化，它就是最好的时间标记。例如艾莉丝修行中头发由短变长（E01 #440–#469 短，#483 起长）。
3. **色/光接力**：相邻两镜共享色相、光向或同一个光源。
   - 例子：FGO cut 64.12；EMIYA #213–#217；边缘行者 cut 156.17（枪口火光 → 爆炸黄）。
   - 快切里每一对相邻镜头至少共享一项：同角色、同色相或同光向。
4. **局部 → 整体**：手 → 脸 → 全景（晚安五条悟：裤脚 → 脸）。
5. **快切串必须有落点**：0.1–0.7 s 的一串动作后，接一个 2–5 s 的稳定脸或长镜。
   - 例子：EMIYA #218 5.0 s；边缘行者 #168 3 s；乔尼 #107 6–7 s。
6. **一击分四段**（鬼灭 #44–#56，117.5 BPM，对拍率是随机的 1.3 倍）：
   - 握柄近景 → 蓄势/下蹲 → 1.5–2 s 全景 → 命中。
   - 最后一击后给一个约 2 s 的余波镜头（#372）。
   - 最后下坠前先停 3–4 s（#324）。
7. **按原作顺序取连续段**
   - 原作本身有修行/战斗连续段落时，先压缩它（保留因果顺序），再按乐句切。
   - 不要从不同季节/地点各抽 1 秒拼起来。用户对 v8 的批评正是这个。

燃向批次（缘一、特级压迫感、献出心脏、一拳超人、命运观测者）的补充：
- 四段式在这些片子里也成立：一击约 1.3 s，分为蓄力 → 斩 → 冲击 → 余波（缘一 #77–#84，一拳超人 #120–#127）。
- 冲击与冲击之间保持同一居中构图，只换颜色。
- 音乐低谷处用溶解加一张字卡把节奏降下来，再用一个约 4 s 的姿态镜头重启。
- 这些片子的密度是 90–130 cpm，对应的是快歌，「光の唄」这类抒情曲不照搬。

## 3. 转场：什么时候可以不是硬切
| 用法 | 条件 | 例 |
|---|---|---|
| 溶解 | 前后两镜亮度相近，且主体位置/形状对齐（眼对眼、脸对脸、圆对圆） | 泛式 dissolve 94.80（冷眼 → 暖眼）；FGO 圆形链 #157–#162；CLANNAD 白 → 白 |
| 一种回忆语言 | 全片只用一种（如纯白 → 画面慢溶解，或 0.1 s 白洗），专表“回忆/时间回溯” | EMIYA 2:58–3:05；晚安五条悟 #30/#66/#98 |
| 黑场 | 段落边界、死亡、孤独。0.1–0.3 s 当“心跳”，2–6 s 当安静节拍 | 认真地活着 #147/#148；人是会改变的 #42–#46 |
| 白 | 只用原作自带的白（爆光、时间魔法、雪原），不叠加白帧 | 利兹与青鸟全片仅 3 次 |
| 不用 | 连闪白、RGB 分离、扫描线、像素故障、径向模糊、撕裂、光晕/星芒、多格拼贴、叠影洪流 | 几乎每部笔记的“不该学”都是这些 |

## 4. 结构与叙事
- **密度曲线：静 → 渐 → 爆 → 收**
  - 开头 20–60 s 用 3–12 s 的长镜头建立前提。
  - 第一次副歌才明显变密。
  - 最密的留给最后一个副歌，紧接静止。
- **对比组织**
  - 明亮日常 ⇄ 黑暗失去。
  - 现在冷、回忆暖。
  - 色彩来自素材选择。
  - 一章一个主色，相邻镜头色相一致。
- **母题**
  - 一个物件/光/手：开头出现，中段出现，结尾带着新含义回来。例子：CLANNAD 光玉、人是会改变的 气泡、JOJO 照片、利兹 钥匙扣。
  - 首尾环形（最后一吻：844 花田首尾）。
- **歌词与剧情**：一句歌词对应一个剧情节点，按剧情时间排；只在“回忆”处打乱顺序。
- **安静节拍**：在全曲 RMS 最低处放 1 个 5–11 s 单镜头（死亡、临终、合上日记），字幕只留一句。
- **单一视角**：有讲述者（老鲁迪的日记）时，其他人都作为“他看到的人”出现，日记句与歌词交替（JOJO 波鲁纳雷夫）。

## 5. 结尾（最后 30–45 s）
共同骨架：
1. 最后高潮之后密度逐级下降（174 → 90 → 6 cpm）。最后 2–3 个镜头各 ≥2.5–3 s。
2. 落点三选一：
   - 孤身人物/背影（骑马离去、独坐、仰望）。
   - 光/天空（日出、白光、空镜）。
   - 物件特写（信、剑、骰子）。
3. 母题回收：开头出现过的画面、地点或光再出现一次。
4. 黑场 2–10 s，与音乐淡出同步。可加一张黑底小字卡（一句话或歌名），不加闪白。

反例：
- 在快切上硬停（NARUTO、认真地活着）。
- 尾声塞新角色或大场面。
- 献词卡、制作卡太长。

## 6. 文字与歌词
**主流做法**：剧情向多数有完整歌词字幕。
- 排版：
  - 底部居中，白字，细描边或柔和暗晕。
  - 双行：原文 + 中文，字号约画面高 3–5%。
- 节奏：一句一屏，不随镜头动，不做逐字弹出。
- 跨快切保持：歌词在多个快切上保持不变，把碎镜头粘成一句话（命运石之门 #195–#217、NARUTO #131–#134）。

**泛式进阶**：
- 大号白字加柔光，高潮句放大。
- 关键词点色，重复句逐字累加。
- 全片 1 次巨字作为情感峰值，放在最后副歌之后。

**分层与字卡**：
- 台词和歌词分层：台词小字或换位置（最后一吻：对白在上，歌词在下）。全片一种字体。
- 黑底字卡全片 2–6 张，放在快切后的低谷：居中小字、宽字距、淡入。

**不要用**：极小灰字（手机读不清）、多层字幕同屏、刷屏说明文字。

**实现**：`scripts/fxkit/lyrics_ass.py`（libass，见 19 号文件）。

## 7. 同系列《无职转生》MAD 的教训
4 部高播放无职 MAD（onelastkiss、认真地活着、爱名为何物、人是会改变的）都没有用 S3 的剑之圣地修行、老鲁迪日记、剑王段落。这块是空白，可以做出差异。

它们的强项：
- 一章一女主、一章一主色，章中心放一个 7–10 s 长镜头。
- 用手部动作当接点：#42 → #45 伸手 → 握手 → 共舞。
- 死亡用“监测器/灯 → 白 → 黑 → 睁眼”的长镜头序列（人是会改变的 #40–#46）。
- 结尾用原作自带的话数标题卡，再接 5 s 黑场。

它们的弱点：
- 像素 glitch、径向模糊、拼贴版面。
- 0.17 s 的叠影串。
- 停在快切上。
- 过暗。

## 8. 工作方法（每个项目都做）
1. 选 6–10 部与目标风格最近的顶尖作品。用 `analyze_mad.py` 拆解，先看 shotboard 与转场条，再写笔记（模板：`mad-study/AGENT_BRIEF.md`）。
2. 对自己的素材做逐集镜头索引：同一工具跑 480p 代理。每镜取首/中/尾三帧做 board，找**原作里的连续段落**（修行、战斗、离别）。
3. 关键段落先出原型，过以下三项检查，并与旧版 A/B。
   - board：每镜首/中/尾帧。
   - cutguard：杂帧检查。
   - redline：闪烁检查。源素材里 >3 次/s 的闪光用 tmix 抑制，这是光敏安全处理，不算装饰。
4. 原型过关后再铺全片。
