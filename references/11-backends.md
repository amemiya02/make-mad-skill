# 后端、能力发现与真实执行范围

## 分工

Agent负责素材研究、导演判断、镜头选择、音乐结构、分镜、工具调用、问题归因与修订决策。脚本负责可重复的媒体探测、时间计算、有限渲染和测量。专业编辑/合成工具负责复杂画轨、速度曲线、抠像、跟踪、2.5D/3D、精细声音与高质量母版。

只有能读视频文件、抽帧或有图像理解，不代表能完整观看连续运动；只有能分析波形，不代表已经听过混音。运行前分别记录这两种能力。缺一项则对应的创作审查保留pending，而不是自动将质量标准降级。

## 已实现CLI

| 子命令 | 输入/输出 | 范围 |
|---|---|---|
| doctor | 环境→JSON | 实际FFmpeg、ffprobe、滤镜/编码器与Python依赖 |
| init | 新目录→项目结构 | 不覆盖非空目录，模板空时间线不能渲染 |
| probe | 本地媒体→JSON | 编码流元数据，不证明原生清晰度/clean source |
| fetch | 确认后的下载清单→文件/来源侧车 | HTTPS直链、体积限制、可选可信hash、视频1080p门 |
| contact | 媒体→缩略图/索引 | 抽样浏览，不是完整观看 |
| scenes | 视频→CSV | 场景变化候选，不是语义分镜 |
| analyze-audio | 音乐工作母带→CSV/JSON | beat/onset/RMS建议，人工确定乐段/情绪 |
| validate | timeline.json→报告 | 严格字段、范围、重叠、声明审核覆盖 |
| render | 合格时间线→MP4/日志 | 单画轨，切/溶解，常量变速，静图推移，多音轨，已有字幕 |
| qa | MP4→JSON | 实解码、时长/帧数/峰值与候选黑场/静止 |
| cutlist | 时间线→CSV | 标注conform单，不冒充原生NLE工程 |

## 明确不支持的基础自动化

复杂蒙版/跟踪、形状morph、粒子系统、三维、真实多层视差、自动抠图、光流/速度坡道、智能对白分离/ducking、自动理解歌词、自动判断参考作品艺术质量、自动生成`.aep/.drp/.blend`、自动发布。

这些不是“永远不做”，而是走真实可用的专业工具。先探测能力，按VFX卡执行，检查结果，保存原生工程和预合成，再回填本时间线。没有工具时交付设计与阻塞，不编造工作已经完成。

## 工具路线选择

有AE/PR：AE做合成/静止系，NLE做全片节奏与声音协调。版本与插件以本机实测为准，不依赖未安装商业插件。

有DaVinci Resolve/Fusion：用实际编辑、Fusion、调色与声音工作区完成；官方培训是核对入口[T09]。不假设免费版本必然包含任何特定高级功能。

有Blender：使用其实际可用的合成/三维能力。当前包提供制作协议，不包含声称已在Blender验证的脚本。

只有FFmpeg：可以做真实的基础剪辑与审片，必要时使用本CLI；不能用堆叠滤镜假装完成复杂空间合成。向用户说明此后端的边界，而非把风格需求偷偷改为简单幻灯片。

## 环境与测试

核心：Python3.10+、FFmpeg/ffprobe（本次测7.1.5）、jsonschema、Pillow。音频分析可选numpy/librosa（本次测0.11.0）。见`examples/environment.json`。

跨操作系统、硬件编码器、所有FFmpeg版本、外部图形编辑器与真实账号下载流程没有一并验证；不同环境先做`doctor`和合成测试。查看`TEST_REPORT.md`，不得从“写了测试脚本”推断“已通过”。
