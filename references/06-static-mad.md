# 静止系MAD：不是自动缩放的漫画幻灯片

用户参考明确包含标记为“静止系MAD”的《芙莉莲》作品[R04]。这支持设置独立工作流，但不代表本包已分析其具体镜头技法。

## 先设计阅读，再设计运动

把图像拆成信息揭示顺序：先看到谁；注意到什么细节；文字何时进入；后景如何改变前景含义；何时允许观众停留。镜头运动要给出新信息，不是为避免静止而不断平移。

漫画连续格的时间关系不能被一个无差别的3D镜头抹平。必要时保持平面阅读；让相邻画格的图形关系成为转场，而不是把每页立成一张卡片。

## 源素材与分层

检查使用范围、来源版本、原始像素、印刷网点/压缩、文字气泡与页面边界。扫描原图、授权数字图或作者素材优先；不能把缩略封面放大当高质量正片。

按前景/主体/背景/可独立运动元素分层；每个图层保持相同画布、参考原点与色彩解释。alpha有无预乘必须明确。图层边缘扩展、背景补画只用于确有必要的合成，不能伪装成找到了不存在的原作画面。没有合法可用图层或补画能力时缩小运动，切回平面构图。

最大推近时检查有效分辨率：例如相机将某张图放大到1.5倍，源中被使用的有效区域应仍满足项目清晰度目标；源文件整体大并不能保证局部裁切足够大。基础脚本的尺寸门只检查源尺寸，不替代这个人工检查。

## 2.5D视差路线

AE：统一画布导入分层 → 合成fps/分辨率 → 图层启用3D并按空间关系分配深度 → 建立摄影机与控制Null → 关键帧只设计必要的位移/视角 → 检查边缘揭露与画外留量 → 对有物理意义的层加入克制景深/运动模糊。

Fusion/Blender同理：多个有透明度的平面或更恰当的几何 → 正确遮挡 → 摄影机 → 输出图层/深度与颜色契约。避免靠极大层间距获得不自然视差；2.5D不是所有镜头都必须转到侧面。

图层原点和深度发生变化时用相机/缩放补偿维持最初画面构图。平面图像没有真实完整几何，侧向运动揭露限制必须显式设计。头发、手、花瓣和衣服只在可解释的部分做局部动作，不能让角色像橡胶一样变形。

## 文字作为空间与时间

台词气泡、作者字幕与动态排版分别处理。不能为方便合成删除原图的作者标识。朗读速度、音乐人声和文字出场共同决定时长；不要在观众还没读完时镜头飞走。重要文字要留最少一次完全稳定的可读状态。

## 基础脚本覆盖什么

`kind=image`加`motion`支持单张静图的平滑推近/推远和焦点平移：`zoom_start/end`以及0到1的`x/y_start/end`。这只是单平面摄影机近似，没有自动分层、真实景深、3D遮挡或动态漫画角色。高级静止系必须按上面路线合成后回填`precomp`。

## 合格判断

运动确实改变了信息与情绪；停顿可以被感到；人物没有因视差失去立体逻辑；没有补画漏底、alpha黑边、纸片穿帮和过度锐化；最后回到全片而非单个合成镜头，确认技术没有抢走作品主题。
