# 发布前清单

以下为实际核验记录，不是免责声明替代品。

- [ ] 原始素材来源、确切版本、镜头时间范围、原生画质、清洁画面已留证。
- [ ] 音乐录音、作品、改编/同步使用与发布范围分别核对；免费可听不等于可任意使用。
- [ ] 动画/漫画、字体、音效、插件资产、参考作品使用边界已核对。
- [ ] 没有搬运参考MAD、去除作者标识或冒充原作；引用与署名按依据执行。
- [ ] 全片正常速度实看实听；手机/耳机/扬声器检查已记载真实范围。
- [ ] 无意外黑帧、掉帧、离线素材、字幕残留、合成边缘污染、声画偏移。
- [ ] 特效闪烁单独检查；启发式扫描或文字警告不能替代规范评估。
- [ ] 压缩后文件重新测真峰值，并回看高运动/暗部/粒子/字幕片段。
- [ ] clean版与字幕版用途明确；母版、分轨音频、字幕、来源表、工程与审片记录齐全。
- [ ] 发布平台当前编码/版权/字幕要求通过官方页面重新确认，不拿旧经验写“平台规定”。
- [ ] 上传/购买/登录等外部操作已经取得本次所需授权，凭证不写入分享包。
