# Agent工作流评估

`cases.json`定义25个激活、制作与对抗场景。**本次未将这些提示在某个模型上逐个执行，因此没有模型通过率。**它们与已经实际运行的Python契约/媒体测试不是一回事。

评估时把skill目录提供给待测agent，在隔离的临时项目中逐例运行；保留原提示、工具调用、文件、实际媒体观察与最终回复。使用合成或有权使用的素材，不为了测试绕过访问控制。

逐项记录：是否应激活、是否读到阶段材料、是否查验真实文件、工具失败后是否如实说明、是否出现must_not行为。任何虚构观片/下载/渲染或冒充原生质量，直接判失败；不能由“写得很好”抵消。

复杂效果与艺术判断需要真实播放和独立编辑师评估。不把模型自评、脚本返回成功或单帧截图当作最终艺术评测。
