# 实际软件验证证据

这些文件来自2026-09-30实际运行的`tests/smoke.py`及`analyze-audio`，不是手工填写的通过报告。

`synthetic-pipeline-test-1080p.mp4`是6秒原创合成素材测试，仅用于证明基础视频链路可执行。它不是AMV作品，不是对用户参考作品的仿作，也不表示艺术质量已验证。

两个子目录分别保留24fps交付规格与24000/1001fps草稿规格测试的JSON、切单与缩略图。它们的`timeline.json`引用由测试脚本生成的本地源；原始合成源不随包重复分发，执行`tests/smoke.py`可完整重建。

日志保留当时容器路径作为执行记录；它们不是用户本机上的有效素材路径。切勿直接将示例中的fixture review=pass复制到真实作品。所有源检查的pass仅标记自制软件测试素材，不是一次虚构的人工AMV审片。

`qa.json`的`loudness.input_i/input_tp`是对成片测得的响度/真峰值；该测量滤镜同时打印的`output_*`只表示它计算的归一化结果，不能当作当前成片的测量值。

测试不包含连续视频观看或音频聆听。只对部分缩略图进行了静态检查。完整结果和限制见`../../TEST_REPORT.md`。
